# DevNotes 💻 (Pet Project)

> Навчальний проєкт персонального технічного блогу з монохромною темною естетикою в стилі термінала.

**DevNotes** — це мій навчальний pet-проєкт, створений для закріплення навичок роботи з бекендом на Node.js/Express, рендерингом сторінок через шаблонізатор EJS та побудовою чистої модульної CSS-архітектури без масивних UI-фреймворків.

---

## 🎯 Мета проєкту

Головна ціль розробки — реалізувати повноцінний цикл роботи вебзастосунку з нуля:
- Зрозуміти взаємодію між клієнтом і сервером через протокол HTTP (обробка `GET` та `POST` запитів).
- Реалізувати базову логіку **CRUD** (Create, Read, Update, Delete) для публікацій.
- Навчитися розділяти інтерфейс на незалежні модулі за допомогою EJS Partials.
- Розподілити стилі на логічні шари (`layout.css` для загального скелета і темної теми, `content.css` для компонентів сторінок).

---

## ✨ Що реалізовано

- **Публікація есе**: форма створення нового запису з назвою, текстом і категоріями.
- **Збереження та відображення**: виведення списку статей на головній сторінці з генерацією динамічних метаданих (дата створення).
- **Редагування та видалення**: параметризовані роути (`/edit/:id`, `/delete/:id`) для зміни або очищення постів.
- **Мінімалістичний інтерфейс**: фокус на читабельність коду й тексту, кастомна темна палітра (`#0F1117`), теплі бурштинові акценти.
- **Сторінка About**: коротка візитка автора з переліком технологічного стека та контактами.

---

## 🛠 Стек технологій

- **Runtime & Framework**: Node.js, Express.js
- **Шаблонізатор**: EJS (Embedded JavaScript)
- **Middleware**: body-parser (для обробки даних із HTML-форм)
- **Стилізація**: кастомний CSS3 (CSS Variables, Flexbox), Font Awesome (іконки)
- **Контроль версій**: Git, GitHub
